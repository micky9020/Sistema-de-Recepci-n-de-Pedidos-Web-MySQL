# 📦 Sistema de Recepción de Pedidos

Sistema web para recepcionar pedidos, almacenarlos en MySQL y generar reportes.

## 🛠️ Tecnologías
- PHP 7.4+
- MySQL 5.7+
- HTML5 / CSS3

## 📋 Funcionalidades
- ✅ Formulario web para ingreso de pedidos
- ✅ Almacenamiento en base de datos MySQL
- ✅ Panel de reportes con estadísticas
- ✅ Reporte diario de pedidos
- ✅ Reportes filtrados por estado (pendiente, en proceso, completado, cancelado)

## 🚀 Instalación

1. Clona el repositorio
2. Importa `database/schema.sql` en MySQL
3. Configura credenciales en `config/db.php`
4. Coloca el proyecto en tu servidor web (XAMPP, Laragon, etc.)
5. Accede a `index.php`
